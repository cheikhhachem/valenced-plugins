## Principles

- **Useful first** — plugins should solve a real annoyance or add a meaningful capability.
- **Polished by default** — clear settings, sensible behavior, and careful edge-case handling.
- **Focused scope** — each plugin should do one thing well instead of becoming a toolbox of unrelated features.
- **Respectful UX** — no unnecessary noise, aggressive automation, or clutter.
- **Transparent releases** — versions, compatibility, and changes should be easy to understand.

## Follow the collection

New plugins and updates will be added to the catalog as they become ready. Until then, this repository is intentionally quiet: no demo plugins, filler packages, or unfinished experiments.
