## Add the repository

Add this catalog URL in Valenced:

```text
https://cheikhhachem.github.io/valenced-plugins/index.json
```

## Plugins

### Fake deafen

Show yourself as deafened in voice while keeping your microphone and local audio settings unchanged.

Use `/fd` or the plugin settings to toggle it, and `/fdstatus` to check its status. Fake deafen requires Vermillion Command Lib, which is available in this catalog. The toggle resets when you leave voice or the gateway socket changes.

### Hidden channels

Show hidden channels already present in the Discord client cache. The plugin has a settings toggle and a diagnostics page.

Channel names are only shown if they are available to the client. The plugin cannot recover redacted names or grant access to private messages.
